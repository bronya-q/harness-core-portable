# CLAUDE.md — project instructions for Claude Code style workflows

## Suggested workflow

- Start with `python harness.py demo --offline`
- Check `python harness.py doctor`
- Use `memory` / `character` / `workspace` commands for daily work
- Write a Task Design doc in `docs/tasks/` before major changes
- Write a Deployment Record in `docs/deployments/` after deployment

## Safety

- No automatic Git push
- No automatic GitHub Release
- No private data in public docs
