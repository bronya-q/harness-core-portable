# v0.3 release preparation

## 1. 一句话目标

在现有 v0.2 基础上，把角色资产化（HCP / Character Card / 事务化 activation / corpus-to-draft）提升到可发布 v0.3 的安全和验证水平。

## 2. 当前状态

- ✅ `character list/install/activate/deactivate/remove/show`
- ✅ `character validate --target public`
- ✅ `character preview`
- ✅ transactional activation backup/rollback
- ✅ `character rollback`
- ✅ `character card-import`
- ✅ `character build --from <corpus> [--approve]`
- ✅ `character mode list/switch/current`
- ✅ HCP 安全安装：path traversal / symlink / ADS / 嵌套 zip / 大小与压缩比 / public script / JSON-PNG MIME 一致性均已有实现与测试
- 🚧 完整 activation 状态机：已有 preflight/status/backup/rollback/recover/lock + 失败注入测试；仍缺真实崩溃/断电/多进程并发全流程回放
- 🚧 Character Card 语义校验仍偏弱
- 🚧 corpus-to-draft 的格式语义校验仍偏弱

## 3. 设计范围

### 本次包含

- HCP 安全安装检查（ADS / MIME / 脚本白名单）已实现；继续保留完整沙箱作为后续项
- 增加 activation 失败注入测试
- 增加 Character Card 字段校验
- 增加 corpus-to-draft 的 holdout 检查
- 准备 v0.3 发布 tag / Release notes / Deployment record

### 本次不包含

- 完整知识桥委派
- 强制文件系统沙箱执行
- 首次用户测试结果

## 4. 公共与本机边界

- 公共包只含合成角色和通用 schema
- 本机私人角色继续留在 local overlay

## 5. 验收标准

- [x] v0.3 HCP 安全校验通过
- [x] 恶意 ZIP 被拒绝
- [x] activation 失败可回滚
- [ ] Character Card 导入校验通过
- [ ] corpus-to-draft 草稿含证据/反证/待审
- [ ] `release_verify` / `package_selfcheck` 通过
- [ ] Deployment record 创建

## 6. 后辈接手说明

1. 先检查 `character validate` 与 `install` 是否强制校验
2. 不要绕过来验证直接安装
3. 发布前重新生成 release manifest
4. 部署后写 Deployment Record
