# Harness Core Portable v0.1.0-alpha.3

> **Pre-release · Alpha/WIP · 本地角色记忆、上下文可见性与角色/知识/工程职责运行台**
> **当前发布状态：GitHub Pre-release 页面已创建。**

v0.1.0-alpha.3 是在 alpha.2 基础上继续推进的版本，重点是：**角色资产化、情境模式、A/B 对照、统一 schema/event/usage、MCP/生态基础、回归测试加固**。

---

## 一句话体验

```bash
git clone https://github.com/bronya-q/harness-core-portable.git
cd harness-core-portable
python harness.py demo --offline
```

Windows 可双击 `开始体验.bat`。

## 相比 alpha.2 新增

### 角色与情境模式

```bash
python harness.py character list
python harness.py character install package.hcp
python harness.py character validate --package package.hcp --target public
python harness.py character preview package.hcp
python harness.py character activate <id>
python harness.py character rollback
python harness.py character card-import --package card.json --output out --yes
python harness.py character build --from corpus/ --output draft --approve
python harness.py character mode list --persona demo-archivist
python harness.py character mode switch --persona demo-archivist --mode archival-research
```

新增：
- HCP 安全校验（path traversal / symlink / ADS / 嵌套 zip / 压缩炸弹 / public 脚本 / MIME）
- 事务化 activation + recover + lock + 失败注入测试
- Character Card 映射
- 语料 → 角色草稿审批
- Situated Mode schema + CLI

### 可组合与对照

```bash
python harness.py ab role --a file-a --b file-b
python harness.py ab retriever --retriever-a keyword --retriever-b atomic --top-k 5 --per-query --meta '{"model":"qwen"}'
python harness.py usage summary
python harness.py usage baseline set --baseline-tokens 1000
python harness.py usage baseline check
python harness.py evidence create --task my-task
python harness.py evidence handoff --task my-task
```

### 知识域 / 工程工作区

```bash
python harness.py knowledge list
python harness.py knowledge sources
python harness.py workspace create --name demo --role ux
python harness.py workspace worktree create --name demo --base HEAD
python harness.py workspace run --name demo -- python harness.py doctor
python harness.py workspace check demo
```

### 统一存储与观测

```bash
python harness.py schema list
python harness.py schema validate --mode <file>
python harness.py event add --scope demo --event-type user_correction
python harness.py event list
python harness.py usage record --actual 640 --baseline 18420 --avoided 17780
```

Notebook 写操作会自动写 event；roleplay 生成后自动记 token 估算；`memory correct` 自动归档旧记录。

### MCP / 生态基础

```bash
python harness.py mcp serve
python harness.py ecosystem status
python harness.py doctor
```

- 官方 FastMCP SDK v1
- `pyproject.toml` 可安装包 + `harness-core-mcp` entrypoint
- OpenAI-compatible adapter
- `docs/mcp/server.json` + `docs/mcp/verification.md`

### 回归测试

```bash
python -m unittest discover
```

覆盖 API / ecosystem / MCP / activation / measurement。

## 当前状态与已知限制

- Alpha/WIP，不是 production-ready
- `activate` 是本地激活标记，不代表全部运行入口热挂载
- HCP 安全校验已大幅加强，但仍缺完整沙箱执行
- Workspace 是元数据 + worktree 创建 + 基本命令约束，不是强制文件系统隔离
- MCP 有 SDK smoke test，但 **Inspector / Official Registry / Claude Code / Codex / Copilot 尚未验证**
- 完整生产门控依赖本地数据，公开包可能返回 `UNAVAILABLE` / `FAIL`
- 不证明心理效度或 AI 意识
