# Harness Core Portable v0.1.0-alpha.4

> **Pre-release · Alpha/WIP · 本地角色记忆、上下文可见性与角色/知识/工程职责运行台**

v0.1.0-alpha.4 是在 alpha.3 基础上继续推进的版本。重点不再是堆新概念，而是把大量 R1 能力做成**可运行、可复现、可观测、可验证**。

---

## 一句话体验

```bash
git clone https://github.com/bronya-q/harness-core-portable.git
cd harness-core-portable
python harness.py demo --offline
python harness.py dashboard build
python harness.py project-check
```
