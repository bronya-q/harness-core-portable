# Harness Core Portable v0.1.0-alpha.2

> **Pre-release · Alpha/WIP · 本地优先的角色记忆、用户控制与只读可视化基础**

这是一个面向试用、审计和反馈的早期版本，不是 production-ready 版本。

---

## 这是什么

Harness Core Portable 是一套本地优先的“角色记忆 / 人格 / 知识 / 工程职责”运行层：

- 让长期使用的 AI 不再每次都像失忆；
- 让不同角色/项目保持记忆隔离；
- 让共享世界设定与私人记忆分开；
- 让用户能查看、纠正、忘记、恢复和清理数据；
- 让公共能力与本机私人角色明确分离。

它不声称 AI 真的有意识、真的理解或真的在乎。

---

## 一分钟确认它有没有用

如果你只想确认项目有什么用，下载 Source code（zip）并解压，然后运行：

```bash
python harness.py demo --offline
```

Windows 用户也可以双击：

```text
开始体验.bat
```

不需要 Ollama，不需要 API key，不使用真实用户数据。离线 Demo 使用完全合成数据，并在结束后自动清理临时目录。

### 你会看到什么

- 跨会话记忆：角色在重新打开会话后仍能召回经历；
- 角色隔离：另一个角色不能读取不属于自己的私人记忆；
- Story Core：角色可以共享世界设定，而不必共享全部私有记录；
- 用户纠错：错误记忆可以被更正；
- 版本恢复：可以查看版本链并恢复旧版本；
- 安全状态：自动执行保持关闭，Demo 不进行网络上传；
- 自动清理：临时合成数据在 Demo 结束后删除。

## 本版新增

### 1. 新手体验入口

```bash
python harness.py start
python harness.py doctor
python harness.py inspect
python harness.py data status
python harness.py demo --offline
```

目标是让新用户先确认环境、数据位置和可见效果，而不是先理解全部内部模块。

### 2. 本地只读 HTML 控制台

```bash
python harness.py dashboard build
python harness.py dashboard open
```

控制台生成本地静态 HTML，不启动服务器、不开放端口。它提供角色/项目、记忆、事件、Story Core、Notebook、Token 使用、运行桥结构和隐私数据流的只读投影。

### 3. 用户可控记忆

```bash
python harness.py memory list --scope <scope>
python harness.py memory explain --id <id>
python harness.py memory correct --scope <scope> --id <id> --text "..."
python harness.py memory restore --scope <scope> --version <version>
python harness.py memory forget --id <id>
```

记忆不应成为只能写入、不能解释和撤销的黑箱。

### 4. 隐私、备份和反馈

```bash
python harness.py privacy status
python harness.py privacy export
python harness.py privacy reset-demo
python harness.py backup create
python harness.py backup list
python harness.py backup restore
python harness.py feedback export --redacted
```

公共发布包不包含真实用户数据、私有人格卡、模型权重或 API key。

### 5. 角色资产基础

```bash
python harness.py character list
python harness.py character install <package>
python harness.py character validate --package <package> --target public
python harness.py character preview <package>
python harness.py character activate <persona_id>
python harness.py character deactivate
python harness.py character rollback
python harness.py character remove <persona_id>
python harness.py character show <persona_id>
```

本版本提供角色包安装、预览、校验和激活状态的基础能力。这里的 `activate` 代表本地激活标记，不代表所有运行入口已经实现全局热挂载。

### 6. 知识域和工程工作区基础

```bash
python harness.py knowledge list
python harness.py knowledge sources
python harness.py workspace create --name <name> --role <role>
python harness.py workspace list
python harness.py workspace status <name>
python harness.py workspace release <name>
python harness.py workspace worktree create --name <name> --base HEAD
python harness.py workspace worktree list --name <name>
python harness.py workspace worktree remove --name <name>
```

这些是知识绑定、工作区元数据和真实 worktree 基础，不应被理解为完整知识委派系统或强制文件系统沙箱。

### 7. 统一 Schema

```bash
python harness.py schema list
python harness.py schema validate --role <file>
python harness.py schema validate --event <file>
python harness.py schema validate --token <file>
python harness.py schema validate --mode <file>
```

本版本包含：

- Unified Role Schema；
- Event Envelope Schema；
- Token Usage Schema；
- Situated Mode Schema。

当前校验属于早期基础实现，不等于完整迁移和兼容性框架。

### 8. Event Envelope 与 Token Usage

```bash
python harness.py event add --scope <scope> --event-type <type>
python harness.py event list --limit 5
python harness.py usage record --actual 640 --baseline 18420 --avoided 17780
python harness.py usage list
python harness.py usage summary
python harness.py usage baseline set --baseline-tokens 1000
python harness.py usage baseline check
```

Token 数据必须区分实际 provider usage、tokenizer 结果和字符估算；“避免注入”不自动等于节约相同金额。

### 9. 公共核心与本机覆盖层分离

本版本开始将公开能力与本机私人角色分开：

```text
Public Core
+ Public Synthetic Examples
+ Private Local Overlay
```

`runtime_resolver.py` 不再以私人角色硬编码作为公共默认入口；本机私有配置可以通过 local overlay 载入。

## 当前状态与已知限制

- Alpha/WIP，不是 production-ready；
- `activate` 不等于所有运行入口中的真正热挂载；
- 角色包完整事务状态机、并发切换和崩溃恢复尚未完成；
- 知识源实际挂载、知识桥委派和角色间受控查询尚未完成；
- 工程 workspace 是基础元数据 + worktree 创建能力，不是强制文件系统隔离沙箱；
- HTML 控制台是静态只读报告，不是交互式本地服务；
- Token usage 的来源和精度取决于记录方式；
- 完整生产门控依赖不随公共仓库发布的本地数据，公开包可能诚实返回 `UNAVAILABLE` 或 `FAIL`；
- 本版本不证明心理学效度，也不证明 AI 真的理解、在乎或具有人类意识；
- 本版本之后 main 分支新增的 situated mode、README 新首屏、A/B、ecosystem bridge、worktree、activation state machine 等内容不属于此 tag。
